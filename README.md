## How to use
``` bash 
# Запустити сервер
python manage.py runserver
```
``` bash
# Запустити тести
python manage.py test recipe
```

*Важливо — команди виконувати з папки де знаходиться manage.py, тобто з recipe_project\, а не з recipe\.*

### Після цього відкрий браузер і перейди на:

- http://127.0.0.1:8000/ — головна сторінка (view main)
- http://127.0.0.1:8000/categories/ — список категорій (view category_list)
